# StudyDuel branding

Selected direction: facing flashcards with a lightning-bolt gap. Indigo #4F46E5 for primary actions, mint #6EE7B7 for decorative highlights, navy #17223B for text, white cards on #F7F8FC. Mint backgrounds require dark text. The generated transparent logo is in assets/studyduel-icon.png.

Expected graduation year is optional (2000–2100), owner-private, editable and removable. The summary shows Class of YEAR beneath the university beside the degree. It does not infer academic year without a program start date. Apply supabase/graduation-year.sql before deploying this version.
